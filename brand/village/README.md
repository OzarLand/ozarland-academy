# OzarLand — Stop 0 : Le village de LUMO

Ce dossier contient la direction artistique complète, l’arc narratif, les fiches personnages, les règles de production et les prompts d’illustration prêts à générer.

- `direction-artistique.md` : document maître en français, avec le manifeste JSON complet en dernière section.
- `manifest.json` : version machine-readable du manifeste ; chaque entrée contient les champs demandés et le prompt complet en anglais.

**Statut des images :** toutes les entrées sont `prompt-only`. Les images raster n’ont pas été générées et ne sont donc pas incluses. Le `target_path` proposé est `overrides/assets/images/ozarland/stop-0/`.

Le système suppose que les légendes et libellés des schémas seront ajoutés en HTML/SVG au moment de l’intégration ; les illustrations générées doivent rester sans texte.
