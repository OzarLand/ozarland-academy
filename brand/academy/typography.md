# Typography

## System stacks

- Interface, body and headings: system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif.
- Code and command output: ui-monospace, SFMono-Regular, Menlo, Consolas, monospace.

No web font or remote font request is used. Use sentence case and keep interface labels literal.

## Type scale

| Role | Desktop size | Mobile size | Weight | Line-height |
|---|---:|---:|---:|---:|
| H1 | 2.5rem | 1.875rem | 700 | 1.15 |
| H2 | 1.875rem | 1.5rem | 700 | 1.25 |
| H3 | 1.375rem | 1.25rem | 650–700 | 1.3 |
| H4 | 1.125rem | 1.125rem | 600–700 | 1.35 |
| Body | 1rem | 1rem | 400 | 1.6–1.65 |
| Small labels / captions | 0.875rem | 0.875rem | 400–600 | 1.45–1.5 |
| Tables | 0.9375rem | 0.875rem | 400 | 1.5 |
| Code | 0.875rem | 0.8125rem | 400–600 | 1.55 |

Use a 68–76 character line length for long-form reading. Never reduce essential body text below 16 CSS px on phones. Keep code horizontally scrollable inside its own labeled block when wrapping would change command meaning.
