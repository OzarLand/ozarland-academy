# Page templates — text wireframes

The global shell remains a familiar Zensical documentation site: branded header, search, theme control, clear navigation, breadcrumbs, readable Markdown content and footer. Use the established image only in the region named below. Keep headings and body copy on solid backgrounds.

## Learning-path home

1. Header: cloud mark, OzarLand Academy, search, theme control.
2. Hero: H1 and one-sentence purpose on a solid parchment plate; path-hero illustration alongside or below; primary action “Start with Discover”.
3. Path: five numbered, visibly connected stop cards in order. Each card has its stage seal, literal module name, one-line outcome and time/skill cue where known.
4. Book panel: clearly separate deeper-reading route; do not label it a sixth step.
5. Shared-learning note: community contribution invitation and source/maintainer links.

On phones, stack hero then five stop cards; retain the ordering and connective path in a vertical rail. Avoid a horizontally scrolling journey.

## Module home

1. Breadcrumb: Academy / module.
2. Module title, accent icon, stage seal and concise outcome statement.
3. Matching section band as a 4:1 image strip; keep title outside the painted pixels.
4. “Start here” action and prerequisites, if any.
5. Ordered content groups using literal headings; show labs, comparisons, studies, runbooks or memos according to the module's actual content.
6. Link to the next learning stop and a separate link to the book.

## Coming soon

Use the coming-soon harbour image as a short, calm state panel. Place a plain heading and explanatory sentence beside it, then a link to the available path stop and a way to return home. Do not announce a release date unless it is confirmed.

## 404 / page not found

Use the not-found image, a direct “Page not found” heading, a short explanation and three recovery links: Academy home, module index and search. Keep focus on the first recovery action after navigation where the site framework supports it. Do not make the scene imply the user is at fault.

## Social preview

Use the included 1200×630 image as the background. Keep its calm title-safe area clear; add the page title and OzarLand Academy name as HTML-generated metadata or a separate overlay render. Use high-contrast text on a solid navy/parchment plate and verify the crop at social card sizes.

## Production memo card — 1080×1350

Portrait 4:5 canvas. Top: small Academy identity and a specific lesson title. Middle: one operational idea, one simple diagram or visual memo, and a short “why it matters” explanation. Bottom: risk classification, safe next action, source/reference link and release context. Keep all essential wording in live text in the source template, not baked into any illustration. Reserve color for module identity and semantic risk labels; each label also contains words and an icon. Provide a text equivalent on the website.
