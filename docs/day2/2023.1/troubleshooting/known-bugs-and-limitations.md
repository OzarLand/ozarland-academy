# Known bugs and limitations

The implementation limitations and bugs found in Kolla-Ansible `2023.1-eol`, by area, with the evidence and the status
of each row. The rows carried over from the Ussuri study keep their area; where an issue no longer holds in 2023.1, the
row says so, with the code that shows it. Where a Status cell adds [NOT AVAILABLE], it names what the sources do not
establish about the issue.

> [!NOTE]
> **Key answers**
>
> - **Implementation limitations and bugs of `2023.1-eol`, by area:** CLI, `site.yml`, `kolla_docker`, the kolla images
>   and individual roles (table below).
> - **No longer holding in 2023.1:** the ignored stop and client timeouts ([F3](../reference/findings.md#f3)), the
>   `-t common` no-op ([F2](../reference/findings.md#f2)), the always-changed OVS `Set system-id`, the
>   neutron-dynamic-routing upgrade gap, the haproxy upgrade bug, the octavia items, the masakari SASL mismatch,
>   `docker_custom_option` and the `ovs-dpdk` `pull` bug.
