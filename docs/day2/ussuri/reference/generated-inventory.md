## 4. Templates that reference inventory groups

**Host list** = the template loops over the group (`for ... in groups[...]`), so the rendered file changes on **every
host that renders it** when the group gains or loses a member. **Other reference** = membership test
(`inventory_hostname in groups[...]`), first-member lookup (`groups[...][0]`) or length check; such a file changes only
where the test result or the referenced member changes.
