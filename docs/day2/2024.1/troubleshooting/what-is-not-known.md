# What is not known

What the sources do not establish, grouped by topic. Each line restates the open point and links to the sections that
mark it [NOT AVAILABLE]; nothing here is an answer. The open questions [Q1–Q21](open-questions.md#q1) are in [Open
questions](open-questions.md). Every point was checked against the 2024.1 pages that mark it: points the 2024.1 code
settles, or that concern 2023.1 code which no longer exists, were removed or narrowed, and the row says so. Points new
in 2024.1 (the Podman path, quorum queues, the staged etcd restart, the systemd unit change, the removed services) are
marked "New in 2024.1".
