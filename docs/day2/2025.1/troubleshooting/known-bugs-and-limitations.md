# Known bugs and limitations

The implementation limitations and bugs found in Kolla-Ansible `2025.1-eom`, by area, with the evidence and the status
of each row. The rows carried over from the 2024.1 study keep their area and their order; where an issue no longer
holds in 2025.1, the row says so, with the code that shows it. Rows that are new in 2025.1 are marked so and come after
the row of their area. Where a Status cell adds [NOT AVAILABLE], it names what the sources do not establish about the
issue; these points are left for the community to confirm.

> [!NOTE]
> **Key answers**
>
> - **Implementation limitations and bugs of `2025.1-eom`, by area:** the CLI, `site.yml`, `kolla_container`, the
>   kolla images and individual roles (table below).
> - **Still present in 2025.1:** the cyborg `serial` play, the placement loadbalancer include, the `--check` blind spot
>   on `permissions` ([F14](../reference/findings.md#f14)), the HAProxy restart instead of reload and its stale files,
>   the RabbitMQ cookie, the MariaDB, Keystone, Glance, Cinder and Heat items, the masakari `qemu+tcp` URI, the Docker
>   restart of `bootstrap-servers` and the certificates that are never renewed.
> - **Changed in 2025.1:** `kolla_serial` cannot batch `reconfigure` or `upgrade` at all
>   ([F19](../reference/findings.md#f19)); a service tag no longer restarts HAProxy, so `genconfig` is no longer the
>   only way to leave a frontend unapplied ([F18](../reference/findings.md#f18)); the Octavia jobboard accepts Valkey.
> - **No longer holding in 2025.1:** the three Bash CLI bugs (`--ask-vault-pass`, `--include-dev`, unquoted command
>   line), the cyborg endpoint variables, the Swift items (the role is removed). Still not holding: the ignored stop and
>   client timeouts ([F3](../reference/findings.md#f3)), the `-t common` no-op ([F2](../reference/findings.md#f2)), the
>   outward RabbitMQ `pull` bug.
> - **New in 2025.1:** a dropped `config.json` entry restarts the container on every run
>   ([F21](../reference/findings.md#f21)); `ovs_wrapper` does not stop the Open vSwitch daemons cleanly
>   ([F22](../reference/findings.md#f22)); the ML2 plugin check reads a result key that no longer exists; the RabbitMQ
>   version check names a command the CLI no longer has; `migrate-container-engine` has no confirmation; Linux Bridge
>   and Swift are removed without a precheck.
